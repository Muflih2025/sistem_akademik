# Matriks kelengkapan fungsi akademik

Audit kelanjutan checkpoint `d53c95f` / kode `620fa27`, 31 Oktober 2026. Referensi: README Laravel lokal read-only, `docs/ABSENSI_DIGITAL_REQUIREMENTS.md`, kebutuhan jurnal/agenda/absensi pengguna, dan `LAPORAN_CHECKPOINT_AKADEMIK_2026-10-31.md`.

**Lengkap** berarti alur development pada fixture benar-benar menyimpan/membaca data dan diuji beserta batas akses terkait. Tidak berarti data sekolah asli sudah dimigrasikan atau produksi disetujui. **Sebagian** menyatakan batas fungsi/cakupan secara eksplisit. **Belum** tidak dihitung sebagai PASS hanya karena tidak masuk suite.

Endpoint utama baru: `GET/POST /academic/index.php?view=...`; seluruh POST memakai CSRF, role/izin backend dan transaksi. Endpoint ekspor: `GET /academic/export.php?kind=...&format=csv|xlsx|pdf|print`. Nama action di bawah adalah parameter POST, bukan simulasi tombol JavaScript.
